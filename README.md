# Chat Platform

Enterprise-grade B2B, B2C, and C2C communication platform.

## Core Features

- 1-to-1 chat
- Group chat
- Audio call
- Video call
- Media sharing
- Realtime presence
- Typing indicators
- Delivery and read receipts
- B2B organizations
- Admin panel
- Moderation
- Notifications

## Tech Stack

### Frontend
- Nx Monorepo
- React Native / Expo
- Next.js
- TypeScript

### Backend
- Phoenix / Elixir
- Microservices architecture
- PostgreSQL
- ScyllaDB
- Redis
- Kafka

### Infrastructure
- Docker
- Kubernetes later
- CI/CD later
